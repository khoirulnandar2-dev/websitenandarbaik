# websitenandarbaik

Website sederhana untuk GitHub Pages yang menampilkan antarmuka biru dan fitur setup biaya bandwidth.

## Fitur

- Halaman utama dengan tema biru modern
- Form pengaturan biaya bandwidth (nama paket, harga per GB, batas bandwidth, diskon)
- Kalkulator biaya bandwidth dengan input pemakaian data dan lokasi backend
- Simulasi penyimpanan pengaturan menggunakan `localStorage`

## Cara deploy di GitHub Pages

1. Push semua file ke cabang `main`.
2. Aktifkan GitHub Pages pada repository:
   - Pilih source: `main` branch
   - Pilih folder: `/ (root)`
3. Buka URL GitHub Pages yang diberikan.

## File utama

- `index.html`
- `styles.css`
- `script.js`
